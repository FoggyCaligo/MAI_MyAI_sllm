# 원격 연결 버튼 사용법 (Windows Remote Agent v1)

**원격 연결** 버튼은 로그인된 Owner에게만 **로그아웃** 버튼 옆에 표시됨. 다른 사용자에게 원격 관리 권한을 부여하지 않음.

1. 현장 PC의 브라우저에서 MAI에 로그인하고 **원격 연결** 클릭.
2. **연결 생성** 클릭하여 일회용 세션 생성.
3. 표시된 `서버`, `세션 ID`를 이용해 현장 PC에서 `mai-remote-agent.exe` 실행. 일회용 키는 현장 PC Agent 콘솔에 직접 입력. 키를 채팅 메시지에 입력하지 말 것.
4. 현장 PC에서 `YES`로 최초 승인. 버튼 상태가 **원격 연결됨**으로 바뀌는지 확인.
5. 기존 채팅창에서 작업 요청. 채팅 API가 선택된 Remote Session ID를 전달하고, MAI의 원격 도구 핸들러는 서버 측에 등록된 해당 세션에 바인딩됨. LLM이 세션 ID를 선택하거나 추측하지 않음.
6. 완료 후 **연결 해제** 버튼을 눌러 서버 세션을 폐기하고, 현장 Agent도 종료·삭제.

연결 패널을 닫는 것은 세션 종료가 아님. 연결 해제를 명시적으로 클릭해야 함. 브라우저가 새로고침되면 세션 키는 브라우저에 저장되지 않으며, 서버의 임시 세션은 만료 시까지 남을 수 있음. 첫 구현은 하나의 탭에서 하나의 원격 대상만 선택함.

## 보안 및 검증

- 현장 PC를 제어하는 권한은 Agent를 실행한 OS 사용자 권한에 따름.
- 현재 버전은 실제 Windows PC 간 종단 간 테스트 및 강제 종료 시 기존 자식 프로세스 정리가 아직 검증되지 않았음. 최초 시험은 본인 소유 PC의 일반 사용자 권한과 임시 테스트 파일을 사용해야 함.
- 원격 Agent의 비밀 키는 노출 시 유효 세션 동안 위험하므로 복사·공유·로그 제출 금지.
- 기능 사용에는 별도 Agent 실행 파일이 필요함. 버튼이 실행 파일을 자동 설치하거나 실행하지 않음.
