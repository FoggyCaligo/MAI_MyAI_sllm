# 브라우저 로그인 세션별 실패 제한

- MAI 로그인 화면에서는 로그인 시도 전에 `GET /login/session`으로 HTTP-only 사전 로그인 세션 쿠키를 발급받음.
- 동일한 브라우저 세션에서 비밀번호 인증 실패가 10회 누적되면 1시간 잠금. HTTP 429와 `Retry-After` 헤더 반환.
- 정상 로그인 성공 시 해당 세션의 실패 횟수만 초기화.
- 다른 브라우저 세션과 IP에는 영향이 없음. Tailscale Funnel 프록시의 공용 IP를 기준으로 차단하지 않음.
- 로그인 실패 기록은 `log.sqlite3`에 세션 토큰 원문이 아닌 SHA-256 해시로 저장하며 서버 재시작 시에도 유지.
- 쿠키는 HttpOnly, Secure, SameSite=Strict, 24시간 만료. 실제 HTTPS 원격 접속을 기본으로 함.
- 쿠키 제거/새 브라우저 세션 생성으로 횟수를 우회할 수 있음. 공격자가 계속 세션을 재발급하면 이 제한만으로는 비밀번호 추측 공격을 막지 못함.
- 사용자가 MAI에서 로그아웃하면 해당 Owner의 임시 원격 관리 세션도 폐기하여 기존 Agent 키를 재사용할 수 없게 함.

## 테스트

동일 세션 9회 실패는 허용, 10회째는 3600초 잠금, 다른 세션은 영향 없음, 1시간 경과 시 다시 시도, 로그인 성공 시 실패 횟수 초기화를 단위 테스트로 확인해야 함.

**구현상 주의:** 이 브랜치는 기존 IP 기준 PR의 내용을 교체한 것으로, 아직 실제 FastAPI/브라우저/Windows Funnel 종단간 테스트가 실행되지 않았음.
