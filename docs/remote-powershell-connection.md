# MAI — 설치 없는 PowerShell 원격 연결

## 의도된 사용 흐름

1. 현장 PC의 브라우저로 MAI에 Owner 로그인.
2. 로그아웃 옆 **원격 연결** 클릭: 서버가 일회용 세션을 생성하고 PowerShell 명령을 클립보드로 복사한 뒤 안내 패널 표시.
3. 동일 PC의 PowerShell에 붙여넣기 후 실행. 원격 관리 권한을 명시적으로 확인하고 `YES` 입력.
4. 브라우저의 **원격 연결됨** 상태 확인 후 MAI에 해당 PC 작업 요청. 채팅의 원격 도구는 브라우저가 선택한 세션에 서버 측에서 묶음.
5. PowerShell이 살아 있고 Agent가 서버에 주기적으로 폴링하는 동안 계속 사용. 원격 연결 버튼의 **연결 해제**는 서버 권한을 즉시 폐기.
6. PowerShell 창을 닫으면 새 명령을 받을 수 없음. 정상 종료 시 Agent가 서버에 세션 회수 요청. 비정상 종료/네트워크 중단 시 회수 요청이 실패할 수 있으므로 마지막 폴링부터 최대 약 180초가 지나면 서버가 해당 세션을 유효하지 않게 판정함.

## 제한

- 새로 발급한 명령을 **최초 실행하기 전**의 유효기간은 10분. 연결 후 사용 시간은 1시간으로 고정하지 않고 Agent 활동마다 갱신.
- 명령에 임시 인증 키가 포함되므로 PowerShell 기록, 클립보드 이력 또는 화면 공유를 통해 유출될 수 있음. 사용 후 명령/키를 다른 사람에게 공유하지 말 것.
- **PowerShell 종료는 신규 원격 작업을 막지만**, 이미 시작된 외부 프로세스가 항상 강제 종료된다고 보장하지 못함. 이 부분은 추가 구현 및 Windows 종단간 검증이 필요함.
- 브라우저만으로 OS를 관리할 수 없으므로 PowerShell을 직접 실행해야 함.
- HTTPS와 MAI Owner 로그인을 요구하며 Agent는 관리자 권한으로 자동 상승하지 않음. 기기 소유자 또는 조직의 허가 범위에서 사용.
- 다른 PC에서 실사용하기 전 본인 소유 테스트 PC에서 일반 사용자 권한으로 검증 필요.
