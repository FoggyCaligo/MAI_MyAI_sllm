# 커밋별 개발 기록

이 문서는 MACHI와 MAI의 Git 커밋을 오래된 순서대로 확인하면서, 각 커밋 직전에 드러난 문제와 해당 커밋이 취한 해결 방향을 간략히 기록한 문서임. 커밋 메시지가 모호한 경우 실제 변경 diff를 기준으로 정리하며, 직접 확인하기 어려운 의도는 과도하게 단정하지 않음.

**커밋 `2f94f41` — MK2**

**직전 문제:** MK1은 파일 기반 프롬프트·기억과 단순 대화 스크립트 중심이라 지속 실행되는 로컬 에이전트, 승인 제어, 구조화된 메모리, UI 및 자율 작업을 운용하기 어려웠음.
