# Rust Core 단일화 결정 (2026-11-15)

- 정식 Agent Core는 **`mai-runtime`** (Tokio 비동기 상태 머신).
- 기존 `mai-core`는 초기 동기식 실험 구현이며 동일 작업 상태 머신의 중복 유지보수가 발생하므로 Cargo workspace 및 브랜치 파일에서 제거했다. 코드/테스트 이력은 이전 Git 커밋 `13fcc0d67a7140ad3b1e2fb0b1e7b35ce419eb66`에서 복구 가능하다.
- 초기 9개 테스트에서 보호하던 직접 완료·도구 활성화·미활성 거부·원자성·취소·빈 입력·모델 오류·중복 이름·도구 결과 등의 핵심 의미는 `mai-runtime/tests/`에 대응하는 비동기 계약 테스트로 이관했다. 테스트 개수 1:1보다 실제 동작이 동등한지에 초점을 맞춘다.
- Verifier, MCP, mcp_memorizer는 이식하지 않는다.
- 기존 HTML/JS UI에는 변경을 하지 않는다.
- 주의: Runtime의 비동기 취소는 향후 실제 외부 프로세스 작업까지 책임지는 것이 아니며, 본 시점에 임시 파일 수명주기나 모든 UI 계약을 구현한 것은 아니다.
