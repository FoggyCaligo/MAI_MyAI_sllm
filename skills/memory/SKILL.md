# Persistent memory

Retrieve missing personal context when the user expects continuity. Memory results are evidence of stored claims, not independent proof of external truth. Bounded retrieval is not exhaustive evidence of absence. Use explicit schemas to choose recall limits; do not guess node IDs. Do not modify memory data unless authorized.
