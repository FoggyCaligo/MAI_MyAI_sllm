# 개인 컴퓨터 관리용 범용 로컬 LLM 에이전트

**사용법: [setup.md — 설치부터 실행까지](setup.md)**

MAI는 개인 컴퓨터에서 실행되는 로컬 AI 에이전트임. 사용자가 허용한 범위에서 대화, 웹 검색, 문서 읽기, 파일·코드 관리, 터미널 명령 실행을 지원함. 답변 생성에는 **Ollama 기반 로컬 언어 모델** 사용.

> 파일 수정·삭제 및 터미널 실행은 실제 컴퓨터에 영향을 줄 수 있음. 중요한 파일은 사전 백업, 외부 접속 설정 전에는 계정과 공개 범위 확인 필요.

## 1. 주요 기능

| 기능 | 지원 내용 |
|---|---|
| **장기기억** | 대화에서 장기간 참고할 사실을 별도 저장소에 기록하고, 이후 대화에서 검색·활용함. |
| **문맥 유지** | 최근 대화 내용을 바탕으로 후속 질문에 답변함. 대화 기록은 장기기억과 별도로 관리함. |
| **웹 검색** | 인터넷 검색, 웹페이지 본문 읽기, 자바스크립트 기반 페이지의 버튼 조작·페이지 이동 등 지원. |
| **증권정보 검색** | 증권시장 정보 조회 도구를 통한 종목 데이터 확인. 조회 항목은 정보 제공처에 따라 달라짐. |
| **파일 구조 확인** | 폴더·하위 폴더 목록, 파일 이름·크기·수정 시각 확인 및 파일 이름 검색 지원. |
| **파일 읽기·관리** | 일반 텍스트·주요 문서 읽기 및 파일 생성·쓰기·삭제·이동·복사 지원. |
| **코드 확인·관리** | 소스코드 검색, 지정한 줄 읽기, 파이썬 코드 구조 확인 지원. 코드 수정·생성·삭제에는 파일 도구 또는 터미널 이용. |
| **터미널 사용** | 프로그램·명령어 실행, 설치·검사 등 로컬 컴퓨터 작업 지원. |
| **이미지 인식** | 별도 영상 인식 모델을 통한 사진·그림 분석. 해당 모델 설정 필요. |
| **음성 대화** | 목소리 등록·화자 비교, 음성의 텍스트 변환, 음성 모드에서 답변 낭독 지원. 음성 답변에는 브라우저 음성 합성 기능 이용. |
| **원격 파일 다운로드 링크** | 웹 화면에서 제공한 파일의 다운로드 링크 이용. 접근 권한 및 서버 실행 상태에 따라 이용 가능 여부가 달라짐. |
| **외부 접속용 사이트** | Tailscale Funnel을 통한 다른 기기의 웹 접속 지원. **Tailscale 설치·로그인·설정 별도 필요.** |

### 지원 파일 형식

**구조화된 문서 읽기 지원 형식**

| 확장자 | 파일 종류 | 읽기 방식 |
|---|---|---|
| `.pdf` | PDF 문서 | 각 페이지의 텍스트 추출 |
| `.docx` | 워드 문서 | 문단과 표 읽기 |
| `.xlsx` | 엑셀 문서 | 시트와 셀 값 읽기 |
| `.csv` | 쉼표로 구분한 표 | 행과 열을 구분해 읽기 |
| `.pptx` | 발표 자료 | 슬라이드 안의 글자 읽기 |

**일반 텍스트 읽기·쓰기 지원 형식:** `.txt`, `.md`, `.log`, `.json`, `.jsonl`, `.yaml`, `.yml`, `.toml`, `.ini`, `.cfg`, `.xml`, `.html`, `.htm`, `.css`, `.js`, `.ts`, `.py`, `.sh`, `.ps1`, `.bat`, `.sql`, `.c`, `.h`, `.cpp`, `.hpp`, `.java`, `.go`, `.rs`, `.rb` 등.

위 확장자는 **텍스트 파일의 예시**임. 실제 텍스트 여부, 인코딩, 접근 권한에 따라 읽기 가능 여부가 달라짐. 이미지·영상·압축파일 등 바이너리 형식은 일반 텍스트 읽기 대상이 아님.

파일 **관리**(생성·쓰기·삭제·이동·복사)는 확장자에 크게 제한받지 않음. 단, `.pdf`, `.docx`, `.xlsx`, `.pptx` 등의 **원래 문서 구조를 유지한 편집**은 별도 문서 도구 또는 터미널 작업이 필요할 수 있음.

코드 검색·읽기는 여러 텍스트 기반 언어를 지원하나, **함수·클래스 구조 자동 분석은 현재 파이썬 코드에 한정됨.**

## 2. 장기기억의 구조와 원리

MAI는 기억을 매번 모델에 장문으로 전달하지 않고 로컬 **그래프 저장소**에 기록함. 그래프는 **노드(점)**와 **에지(연결선)**로 구성됨.

### 그래프 구조

```text
[사용자 기준점]
       │ 사실을 기억함
       ▼
 [사실 노드] ── 관련 개념 ──▶ [개념 노드]
```

- **사용자 기준점 노드:** 기억의 대상 사용자를 구분하는 기준점.
- **사실 노드:** 대화에서 확인된 지속적 참고 정보를 저장하는 노드.
- **개념 노드:** 유사한 기억을 찾기 위한 검색 단서.
- **에지:** 사용자·사실·개념 사이의 관계를 표시하는 연결선.

대화 **원문은 별도 근거 기록**으로 보존함. 원문마다 별도의 그래프 노드를 무한히 생성하는 구조는 아님.

### 기억 저장 과정

1. 대화 종료 후 **로컬 언어 모델이 기억할 만한 사실 추출**.
2. **Sentence Breaker 등의 알고리즘**으로 검색용 개념 정리.
3. 사실·개념을 그래프에 연결하고 원래 사용자 발화는 별도 근거 기록으로 보존.

**사실 추출에는 LLM을, 그래프 구성·개념 색인에는 별도 알고리즘을 사용함.** 모든 저장 과정이 LLM 없이 동작하는 것은 아님.

### 기억 검색 과정

1. MAI의 모델이 필요한 기억을 질문 형태로 조회.
2. 검색어를 공백 기준으로 분리하고 개념 색인에서 **정확 일치 및 SQLite 전문 검색(FTS5)**으로 후보 검색.
3. 연결된 사실 노드를 가져와 답변 생성에 활용.

MAI는 과거 대화 전체 대신 **개념 색인으로 필요한 사실만 조회**함. 주요 데이터는 `data/memory.sqlite3`에 저장하며, 임베딩·벡터 검색을 핵심 식별 체계로 사용하지 않음.

최근 대화 문맥: `data/chat.sqlite3` / 실행·오류 기록: `data/log.sqlite3`.

상세 구조: [기억 구조 문서](WORKING_CONTRACT.md) 참조.

## 3. 처음 설치하는 방법

**Windows 10/11:** 관리자 권한으로 **PowerShell** 실행 후 다음 명령 전체 붙여넣기 및 실행.

```powershell
$installer = Join-Path $env:TEMP 'mai_install_windows.ps1'
Invoke-WebRequest -Uri 'https://raw.githubusercontent.com/FoggyCaligo/MAI_MyAI_sllm/dev/scripts/install_windows.ps1' -OutFile $installer
powershell -NoProfile -ExecutionPolicy Bypass -File $installer
```

설치 과정: Git·Python·Ollama 설치 상태 확인 → MAI 다운로드 → 가상환경·필수 라이브러리 설치 → 브라우저 구성요소 설치. 사용자 계정 비밀번호와 모델 이름 등은 설치 중 직접 입력 필요.

**설치 스크립트는 인터넷에서 다운로드하여 실행되므로** [스크립트 내용](scripts/install_windows.ps1) 사전 확인 권장. 기존 `.env` 및 기억·대화 데이터는 덮어쓰지 않도록 구성됨. 설치 환경에 따라 추가 조치가 필요할 수 있음.

Tailscale 외부 접속은 자동 공개되지 않음. 외부 접속·계정 관리·오류 해결: **[setup.md](setup.md)** 참조.

## 4. 이후 실행하는 방법

**서버 실행:** 일반 권한 터미널에서 MAI 폴더로 이동 후 다음 명령 실행.

```bash
python run_server.py
```

**Windows 실행 순서:** 프로젝트 폴더 이동 → 가상환경 활성화 → 서버 실행.

```powershell
cd "$env:USERPROFILE\Documents\Git\MAI_MyAI_sllm"
.\.venv\Scripts\Activate.ps1
python run_server.py
```

**로컬 접속:** http://127.0.0.1:8000  
**외부 접속:** Tailscale Funnel 별도 설정 필요.

**문제 해결:** [설치·실행·오류 해결 안내서](setup.md) 참조.
