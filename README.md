# 개인 컴퓨터 관리용 범용 로컬 LLM 에이전트

**사용법: [setup.md — 설치부터 실행까지](setup.md)**

MAI는 개인 컴퓨터에서 실행되는 인공지능 비서임. 대화 기능 외에도 사용자가 허용한 범위에서 웹 검색, 문서 열람, 파일 및 코드 관리, 터미널 명령 실행 등을 지원함. 답변 생성에는 **Ollama로 실행하는 로컬 언어 모델**을 사용함.

> 파일 수정·삭제와 터미널 실행은 실제 컴퓨터에 영향을 줄 수 있음. 중요한 파일은 사전에 백업하고, 외부 접속을 설정하기 전에 계정과 공개 범위를 확인해야 함.

## 1. 주요 기능

| 기능 | 지원 내용 |
|---|---|
| **장기기억** | 대화에서 지속적으로 참고할 만한 사실을 별도 저장소에 기록하고, 이후 대화에서 검색하여 활용함. |
| **문맥 유지** | 최근 대화 내용을 이어받아 후속 질문에 답변함. 대화 기록은 장기기억과 별도로 관리함. |
| **웹 검색** | 인터넷 검색, 웹페이지 본문 읽기, 자바스크립트로 표시되는 페이지의 버튼 조작 및 페이지 이동 등을 지원함. |
| **증권정보 검색** | 증권시장 정보 조회 도구로 종목 관련 데이터를 확인할 수 있음. 조회 가능 항목은 연결된 정보 제공처에 따라 달라짐. |
| **파일 구조 확인** | 폴더 및 하위 폴더 목록, 파일 이름·크기·수정 시각 확인, 파일 이름 검색 등을 지원함. |
| **파일 읽기·관리** | 일반 텍스트와 주요 문서의 읽기, 파일 생성·내용 쓰기·삭제·이동·복사를 지원함. |
| **코드 확인·관리** | 소스코드 검색, 지정한 줄 읽기, 파이썬 코드 구조 확인을 지원함. 코드 수정·생성·삭제에는 파일 도구 또는 터미널을 사용함. |
| **터미널 사용** | 프로그램 및 명령어 실행, 설치·검사 등 로컬 컴퓨터 작업을 수행할 수 있음. |
| **이미지 인식** | 별도로 지정한 영상 인식 모델로 사진이나 그림을 분석함. 해당 모델이 설정되지 않은 경우 이용할 수 없음. |
| **음성 대화** | 목소리 등록·화자 비교, 음성의 텍스트 변환, 음성 모드에서의 답변 낭독 기능을 제공함. 음성 답변에는 브라우저의 음성 합성 기능을 사용함. |
| **원격 파일 다운로드 링크** | 웹 화면에서 생성·제공한 파일을 내려받는 링크를 사용할 수 있음. 이용 가능 여부는 접근 권한과 서버 실행 상태에 따라 달라짐. |
| **외부 접속용 사이트** | Tailscale Funnel 설정 시 다른 기기에서도 웹주소로 접속할 수 있음. **Tailscale 설치·로그인·설정이 별도로 필요함.** |

### 지원 파일 형식

**문서 내용을 구조적으로 읽을 수 있는 형식**은 다음과 같음.

| 확장자 | 파일 종류 | 읽기 방식 |
|---|---|---|
| `.pdf` | PDF 문서 | 각 페이지의 텍스트 추출 |
| `.docx` | 워드 문서 | 문단과 표 읽기 |
| `.xlsx` | 엑셀 문서 | 시트와 셀 값 읽기 |
| `.csv` | 쉼표로 구분한 표 | 행과 열을 구분해 읽기 |
| `.pptx` | 발표 자료 | 슬라이드 안의 글자 읽기 |

**일반 텍스트로 읽고 쓰는 형식**에는 `.txt`, `.md`, `.log`, `.json`, `.jsonl`, `.yaml`, `.yml`, `.toml`, `.ini`, `.cfg`, `.xml`, `.html`, `.htm`, `.css`, `.js`, `.ts`, `.py`, `.sh`, `.ps1`, `.bat`, `.sql`, `.c`, `.h`, `.cpp`, `.hpp`, `.java`, `.go`, `.rs`, `.rb` 등이 있음.

위 목록은 **텍스트로 저장된 파일의 예시**임. 확장자가 같더라도 실제 파일 내용이 텍스트여야 하며, 문자 인코딩이나 접근 권한에 따라 읽지 못할 수 있음. 텍스트 파일은 확장자에 관계없이 읽을 수 있는 경우가 많으나, 이미지·영상·압축파일 등의 바이너리 형식은 일반 텍스트 읽기로 처리하지 않음.

파일 **관리**(생성·내용 쓰기·삭제·이동·복사)는 확장자 자체에 크게 제한받지 않음. 다만 `.pdf`, `.docx`, `.xlsx`, `.pptx`를 **원래 문서 구조 그대로 편집하는 전용 기능**과는 구별해야 함. 구조화된 문서 수정에는 문서 생성 도구나 터미널 작업 등 별도 처리가 필요할 수 있음.

코드 검색·읽기는 여러 텍스트 기반 프로그래밍 언어에 사용할 수 있으나, **코드의 함수·클래스 구조를 자동 분석하는 전용 기능은 현재 파이썬 코드에 한정됨.**

## 2. 장기기억의 구조와 원리

MAI는 기억을 매번 긴 문장으로 모델에 전달하는 대신, 컴퓨터 내부의 **그래프 형태 저장소**에 기록함. 그래프는 **노드(점)**와 **에지(연결선)**로 구성됨.

### 그래프 구조

```text
[사용자 기준점]
       │ 사실을 기억함
       ▼
 [사실 노드] ── 관련 개념 ──▶ [개념 노드]
```

- **사용자 기준점 노드:** 기억이 누구에 관한 것인지 구별하는 출발점임.
- **사실 노드:** 대화에서 확인한 지속적으로 참고할 만한 정보를 저장함.
- **개념 노드:** 유사한 내용의 기억을 검색하기 위한 단서임.
- **에지:** 사용자와 사실, 사실과 개념 사이의 관계를 나타냄.

대화의 **원문은 별도 근거 기록**으로 보존함. 원문마다 새로운 그래프 노드를 무한히 생성하는 방식은 아님.

### 기억 저장 과정

1. 대화 종료 후 **로컬 언어 모델이 기억할 만한 사실을 추출함.**
2. 추출한 사실을 저장할 때 **Sentence Breaker 등의 알고리즘**으로 검색용 개념을 정리함.
3. 사실과 개념을 그래프에 연결하고, 원래 사용자 발화는 별도 근거 기록으로 보존함.

즉, **사실 추출에는 LLM을 사용하고 그래프 구성·개념 색인에는 별도의 알고리즘을 사용함.** 저장 과정 전체가 LLM 없이 작동하는 구조는 아님.

### 기억 검색 과정

1. 모델이 현재 필요한 기억을 질문 형태로 조회함.
2. 검색어를 공백 기준으로 분리하고, 저장된 개념 색인에서 **정확 일치 및 SQLite 전문 검색(FTS5)**으로 후보를 검색함.
3. 연결된 사실 노드를 가져와 답변 생성에 참고함.

검색할 때마다 과거 대화 전체를 모델에 다시 전달하지 않음. **개념을 통해 필요한 사실만 선별하여 가져오는 구조**이며, 저장소의 주요 데이터는 `data/memory.sqlite3`에 보관됨. 별도의 임베딩·벡터 검색 공간을 핵심 식별 체계로 사용하지 않음.

최근 대화 문맥은 `data/chat.sqlite3`, 문제 확인용 실행 기록은 `data/log.sqlite3`로 구분하여 관리함.

상세 구조는 [기억 구조 문서](WORKING_CONTRACT.md)에서 확인할 수 있음.

## 3. 최초 설치 방법

**Windows 10/11**에서는 관리자 권한으로 **PowerShell**을 실행한 뒤 아래 명령 전체를 **한 번에 붙여넣어** 실행함.

```powershell
$installer = Join-Path $env:TEMP 'mai_install_windows.ps1'
Invoke-WebRequest -Uri 'https://raw.githubusercontent.com/FoggyCaligo/MAI_MyAI_sllm/dev/scripts/install_windows.ps1' -OutFile $installer
powershell -NoProfile -ExecutionPolicy Bypass -File $installer
```

설치 과정에서는 Git·Python·Ollama 등의 설치 상태 확인, MAI 다운로드, 가상환경 및 필요 라이브러리 설치, 웹 브라우저 실행 구성요소 설치 등을 진행함. 사용자 계정 비밀번호와 사용할 모델 이름 등은 설치 도중 직접 입력해야 함.

**설치 명령은 인터넷에서 스크립트를 내려받아 실행하므로**, 실행 전에 [설치 스크립트 내용](scripts/install_windows.ps1)을 확인하는 것을 권장함. 기존 `.env`와 기억·대화 데이터는 덮어쓰지 않도록 구성되어 있음. 실제 Windows 환경에서는 설치된 프로그램과 설정에 따라 추가 조치가 필요할 수 있음.

Tailscale을 통한 외부 접속은 자동 공개되지 않음. 외부 접속 설정, 계정 관리, 오류 해결을 포함한 자세한 안내는 **[setup.md](setup.md)**에서 확인할 수 있음.

## 4. 이후 실행 방법

설치를 완료한 후 일반 권한의 터미널을 열어 MAI 폴더에서 다음 명령을 실행함.

```bash
python run_server.py
```

Windows에서 최초 설치 후 필요한 경우, 먼저 프로젝트 폴더로 이동하여 가상환경을 활성화함.

```powershell
cd "$env:USERPROFILE\Documents\Git\MAI_MyAI_sllm"
.\.venv\Scripts\Activate.ps1
python run_server.py
```

서버 실행 후 같은 컴퓨터의 브라우저에서 **http://127.0.0.1:8000**에 접속할 수 있음. 외부 접속은 Tailscale Funnel을 별도로 설정한 경우에만 가능함.

문제 발생 시 **[설치·실행·오류 해결 안내서](setup.md)**를 참고함.
