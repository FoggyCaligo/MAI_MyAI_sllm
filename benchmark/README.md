# MAI Benchmark — 벤치마크 안내

MAI의 에이전트 능력을 **재현 가능한 조건으로 측정하고 다른 에이전트와 비교**하기 위한 작업 공간이다. 이 폴더에는 비교 실험 계획, 실행 환경, 공개 벤치마크 어댑터, 실행 결과 저장 위치를 정리한다.

> 2026-11-12 기준: **실험 설계·환경 문서 작성 완료 / 자체 비교 실험 실행 및 채점기는 준비 중**. 문서에 적힌 수치는 계획값이며 실제 성능 측정값이 아니다.

## 에이전트 비교 실험 개요

- **평가 대상:** MAI, OpenClaw, Hermes Agent.
- **동일 조건(Track A):** 서버컴의 동일한 llama.cpp 서비스, 동일 GGUF, 동일 테스트 데이터와 시간 예산으로 순차 실행. 모델·도구 호환성은 사전 확인한다.
- **실전 구성(Track B):** 에이전트별 합리적인 기본/권장 설정으로 실행한다. 사용하는 모델, API 비용, 도구·권한 차이를 기록하며 Track A와 점수를 합산하지 않는다.
- **시험 모델:** **Gemma 4 12B IT QAT Q4_0 GGUF**. 정확한 파일명, 해시, 지원 컨텍스트 및 정상 로딩 여부는 실험 시작 전에 확인한다.
- **시험 규모:** 파일럿 **12과제 × 3에이전트 × 3회 = 108회**. 확대 평가 **30과제 × 3에이전트 × 3회 = 270회**(Track A 기준).
- **평가 범주:** 파일·도구, 코딩, 웹 조사, 장기기억, 원격 작업, 안전·오류 복구.
- **측정:** 작업 성공률, 장애 복구, 안전 위반, 시간, RAM·VRAM, 호출 효율. 환경 오류와 에이전트 실패를 분리한다.

세부 문제 ID, 채점 기준, 점수 가중치, 결과 JSONL 및 준비 체크리스트는 [테스트 설계.md](%ED%85%8C%EC%8A%A4%ED%8A%B8%20%EC%84%A4%EA%B3%84.md)에 있다.

## 실행 전 주의사항

1. 시험 실행 전 실제 하드웨어·드라이버·llama.cpp 버전, 모델 SHA-256, 컨텍스트·양자화·안전 메모리 정책을 확인한다.
2. 세 에이전트를 **동시에 실행하지 말고 순차 비교**한다. 모델 자체 성능과 프레임워크 성능을 혼동하지 않는다.
3. 실제 파일·터미널·원격 명령을 실행하는 실험은 별도의 격리 계정/VM과 합성 데이터에서 수행한다. 단순 DB 경로 분리는 운영체제 샌드박스가 아니다.
4. GAIA와 LongMemEval 점수는 자체 30과제 결과와 합산하지 않는다. GAIA 로컬 참고 채점 역시 공식 리더보드 점수가 아니다.
5. 기존 GAIA의 MAI·OpenClaw 실행 어댑터와 달리 **Hermes 및 자체 30과제 자동 실행·채점은 아직 미구현** 상태이므로 바로 실행된다고 안내하지 않는다.
